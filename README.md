# 3D Model Gallery

Небольшой интерактивный просмотрщик 3D-моделей для GitHub Pages. Работает в браузере, без сборки и backend-сервера.

## Возможности
- Загрузка нескольких моделей с компьютера или drag-and-drop.
- Переключение между моделями в списке.
- Вращение мышью, масштабирование колёсиком, перемещение правой кнопкой.
- Автоповорот и каркасный режим.
- Форматы: `.glb`, `.gltf`, `.obj`, `.stl`.
- Подгонка модели под сцену автоматически.
- Адаптация под мобильные экраны.

## Запуск локально
Для ES-модулей лучше открыть сайт через локальный сервер, а не двойным кликом по `index.html`.

Например, если установлен Python:
```bash
python -m http.server 8000
```
Открой `http://localhost:8000`.

## Публикация на GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория `index.html` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Через минуту сайт будет доступен по адресу `https://ТВОЙ-USERNAME.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Как добавить модели, которые будут доступны всем посетителям
Сейчас загрузка через интерфейс временная: файлы выбираются с устройства посетителя и не загружаются в GitHub.

Чтобы сделать постоянное портфолио:
1. Создай папку `models` в репозитории и положи туда модели.
2. Для GLB удобнее всего использовать один самодостаточный `.glb` файл с текстурами внутри.
3. Чтобы показать модели сразу на странице, можно добавить их в код или расширить сайт до галереи, читающей `models/manifest.json`.

## Поддержка форматов
- **GLB** — рекомендуется, обычно содержит геометрию и текстуры в одном файле.
- **GLTF** — если есть внешние текстуры или `.bin`, выбирай связанные файлы вместе.
- **OBJ** — геометрия; материалы и текстуры могут потребовать дополнительные файлы `.mtl` и изображений.
- **STL** — геометрия без встроенных материалов/текстур.

Three.js загружается с CDN, поэтому для работы нужен интернет.
